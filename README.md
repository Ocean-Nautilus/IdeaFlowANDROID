IdeaFlow — приложение на Android для записи и хранения идей. В нём можно быстро сохранить мысль, добавить к ней категорию, а потом легко найти нужную идею через поиск и фильтры.

О приложении
Приложение подходит для людей, которые хотят не забывать свои идеи: мысли о проектах, покупках, учёбе, работе или творчестве. Каждую идею можно сохранить с названием, описанием, датой и категорией.

IdeaFlow помогает не просто хранить заметки, а видеть, какие идеи есть, к какой теме они относятся.
Основные функции

    Добавление идей: название, описание, дата, категория

    Редактирование и удаление идей

    Просмотр подробной информации об идее

    Поиск по названию или описанию

    Настройки: тёмная тема, сортировка по умолчанию и другие параметры

Экраны приложения

    Главный экран - список всех идей с поиском и кнопкой добавления.

    Экран добавления и редактирования — форма для создания или изменения идеи

    Экран идеи - полная информация об идее и кнопки «Редактировать» и «Удалить»

    Экран статистики - графики и числа по идеям пользователя

    Экран настроек - управление темой, сортировкой и другими параметрами
