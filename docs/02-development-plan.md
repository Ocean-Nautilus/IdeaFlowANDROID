# План разработки на 12 недель

Проект: **«Идеи»** — запись случайных мыслей.
Тема №17 технического задания по МДК 01.03.

Каждая неделя закрывается отдельным коммитом. Принцип разбиения:
сначала данные, потом экраны поверх них, в конце — изюминка и оформление.

| Неделя | Что делается | Результат, который видно |
|--------|--------------|--------------------------|
| 1 | Каркас: одна Activity, четыре фрагмента, нижнее меню, палитра и тёмная тема | Приложение запускается, вкладки переключаются |
| 2 | База данных Room: 4 таблицы, связи, тестовые данные | Таблицы видны в Database Inspector, тесты связей проходят |
| 3 | Список идей: RecyclerView, адаптер, ViewModel, пустое состояние | Главный экран показывает идеи из базы |
| 4 | Создание и редактирование идеи: форма, валидация полей | Идею можно добавить и изменить |
| 5 | Детальный просмотр и удаление с диалогом подтверждения | Полный CRUD закрыт |
| 6 | Категории: экран управления из настроек | Создание, изменение названия и цвета, удаление с подтверждением; последнюю категорию удалить нельзя |
| 7 | Теги исключены по решению пользователя 20.10.2026 | В интерфейсе тегов нет; старые связи в базе и резервных копиях оставлены для совместимости |
| 8 | Поиск по тексту, два фильтра (категория и статус), сортировка | Список ищется, фильтруется и сортируется |
| 9 | Экран статистики: круговая и столбчатая диаграммы на MPAndroidChart | Графики по реальным данным пользователя |
| 10 | Настройки: тема, показ описания, экспорт и импорт данных | Тема переключается, данные переносятся JSON-файлом; сортировка остаётся в списке идей |
| 11 | **Изюминка:** голосовой ввод описания через системное распознавание речи | Описание надиктовывается и редактируется; реализовано, проверено на телефоне (см. `07-voice-input.md`). Метка в списке убрана по пожеланию пользователя |
| 12 | Обработка ошибок, пустые состояния, тесты, README, руководство, визитка | Проект готов к сдаче |

## Пять обязательных экранов

ТЗ требует минимум пять. У приложения их ровно пять:

1. **Список идей** — главный экран, вкладка нижнего меню
2. **Создание/редактирование** — открывается кнопкой «+» и по кнопке «Изменить»
3. **Детальный просмотр** — открывается нажатием на элемент списка
4. **Статистика** — вкладка нижнего меню
5. **Настройки** — вкладка нижнего меню

Экран управления категориями (неделя 6) — шестой, открывается из настроек.
