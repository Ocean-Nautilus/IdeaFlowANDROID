# Исправления и проверка — 13 октября 2026

## Изменения

- Редактирование сохраняет исходную дату создания и признак голосовой заметки.
- Фильтр категорий заново подключается после возврата из карточки.
- Русские окончания количества идей выбираются независимо от языка телефона.
- При пустом результате поиска предлагается изменить запрос или фильтры.
- Шапка списка сворачивается при прокрутке, освобождая место в горизонтальном положении.
- Выбранный статус восстанавливается при пересоздании экрана.
- Высота прокручиваемой области карточки ограничена оставшимся местом под шапкой.
- Настройки и схема базы данных не изменялись.

## Автоматические проверки

- Добавлен тест редактирования: сохранение даты, голосового признака и тегов без дублирования идеи.
- Добавлен тест окончаний для 0, 1, 2, 4, 5, 8, 9, 11, 12, 14, 21, 22, 25, 111 при английской и русской конфигурации.
- Проверка XML-разметки: пройдена.
- Сборка, локальные тесты и Android Lint: результат будет указан после завершения запуска.
- Тесты на Android-устройстве ещё не запускались; подключение отложено пользователем.

## Проверка на телефоне после подключения

- [ ] Запуск обновлённой сборки с сохранением пользовательских записей.
- [ ] Создание тестовой идеи, пустой заголовок и ограничение длины заголовка.
- [ ] Редактирование названия, описания, категории, статуса и важности.
- [ ] Дата создания не меняется, дата изменения обновляется, теги сохраняются.
- [ ] Поиск по названию и описанию, пустой результат, очистка запроса.
- [ ] Каждый статус, каждая категория, совместное применение фильтров.
- [ ] Фильтр категорий после открытия карточки и возврата.
- [ ] Все четыре варианта сортировки.
- [ ] Поворот списка с поиском и фильтрами, прокрутка до последних записей.
- [ ] Поворот незавершённой формы: поля сохраняются, доступны прокрутка и сохранение.
- [ ] Поворот карточки с длинным описанием: нижние поля доступны при прокрутке.
- [ ] Статистика в обеих ориентациях, прокрутка и обновление после изменений.
- [ ] Уход в фон и возврат; сохранение рядом с поворотом экрана.
- [ ] Отмена удаления и подтверждённое удаление только тестовых записей.
