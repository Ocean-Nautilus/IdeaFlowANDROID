# Настройки и темы — 16 октября 2026

Обновление по запросу пользователя: сортировка по умолчанию удалена из настроек; сортировка остаётся только в списке идей. Вместо неё добавлены экспорт и импорт — см. `06-export-import.md`. Ниже сохранён отчёт о предыдущей версии настроек.

Реализованы:
- Тёмная, светлая и системная темы. Выбор применяется сразу и сохраняется после закрытия приложения.
- Четыре варианта сортировки по умолчанию. Изменение применяется при возврате к списку и при запуске приложения.
- Показ или скрытие описаний в карточках списка. Полный текст идеи не изменяется.
- Прокрутка настроек в горизонтальном положении.
- Контрастный текст кнопок, системных панелей и отложенного статуса в светлой теме.

Настройки хранятся во встроенном SharedPreferences. Новые зависимости не добавлены; схема базы и идеи не изменялись. При первом запуске сохранено прежнее поведение: тёмная тема, новые идеи сверху, описания видимы.

Ручная сортировка через меню списка действует до нового запуска или изменения настройки сортировки; возврат из карточки её не сбрасывает.

## Проверки

Добавлен AppSettingsTest: значения по умолчанию, сохранение всех режимов темы и сортировки, переключателя описаний, возврат к значениям по умолчанию при неизвестных сохранённых значениях.

Результаты:
- Debug APK и тестовый APK собраны; обновление установлено поверх предыдущей версии без очистки данных.
- Локальный тест: 1 пройден.
- Инструментальные тесты на Infinix X6833B, Android 14: 6 пройдены (AppSettingsTest, IdeaCountFormatterTest и четыре DatabaseTest).
- Android Lint: 0 ошибок, 26 предупреждений.
- На телефоне проверены все три темы, повторное переключение, сохранение после закрытия, следование за светлой и тёмной системной темой.
- Проверены применение сортировки по названию, её сохранение после закрытия, скрытие и повторный показ описаний.
- Настройки прокручиваются в горизонтальном положении. Системная тема и ориентация телефона после теста возвращены к исходным.
- Во время проверки пользовательские идеи не создавались, не редактировались и не удалялись. Количество совпадает с исходным.

При проверке исправлено восстановление выпадающих полей: их значения читаются из настроек, чтобы Android не фильтровал список до одного пункта после смены темы. Оформление нижней системной панели вынесено в ресурсы API 27+, сохранив поддержку Android 7.

Старый незавершённый сценарий LongTextEditorTest в этот запуск не включён и остаётся отдельной задачей. На Android 7–13 и других моделях телефонов новая версия не запускалась.
