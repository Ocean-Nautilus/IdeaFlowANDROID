# Экспорт и импорт — 16 октября 2026

Сортировка убрана из настроек вместе с сохранением сортировки по умолчанию. Меню сортировки на экране идей работает как раньше. Тема и переключатель описаний сохранены.

## Перенос данных

В настройках добавлены кнопки «Экспортировать данные» и «Импортировать данные». Для выбора файла используется системный диалог Android; дополнительных разрешений на хранилище нет.

Экспорт создаёт JSON IdeaFlow версии 1. Файл содержит все идеи, категории и теги, включая неиспользуемые категории и теги. У идей сохраняются название, описание, даты, статус, важность, признак голосовой заметки и связи с тегами. Настройки оформления в файл не входят.

Импорт добавляет данные к существующим:
- Категории и теги сопоставляются по точному названию. Уже имеющиеся категории не перекрашиваются.
- Числовые идентификаторы переназначаются, чтобы избежать конфликтов с существующими записями.
- Полные совпадения идей и тегов пропускаются. Количество одинаковых идей, намеренно сохранённых в исходной базе, сохраняется.
- После завершения показывается число добавленных и пропущенных идей.

Файл проверяется полностью перед записью. Проверяются версия, поля, типы, диапазон важности, идентификаторы и ссылки. Импорт выполняется одной транзакцией: ошибка записи откатывает все изменения. Экспорт читает согласованный снимок базы.

Ограничение файла — 10 МБ, указано на экране. Чтение ограничено до разбора JSON. Операции выполняются вне главного потока и продолжаются при повороте экрана. Ошибки отображаются сообщением; повторный запуск во время операции блокируется.
