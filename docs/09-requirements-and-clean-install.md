## Условия проверки чистой установки

Создано отдельное устройство `IdeaFlowCleanQA`, Android 13 / API 33, Google Play x86_64, отдельные данные в `.gradle/clean-install-qa`. Все ADB-действия закреплены за `emulator-5580`. Телефон и существующий Pixel 7 не очищались и не использовались для проверки. APK установлен как новый пакет, без `-r`; до установки пакета приложения на эмуляторе не было.

Первый запуск: успешен, 6 демонстрационных идей и 3 категории. Проверены четыре таблицы и отсутствие нарушений внешних ключей. Повторный холодный запуск не дублирует демонстрационные записи. Через интерфейс создана дополнительная тестовая идея.

Экспорт через системный файловый диалог создал JSON с 7 идеями. Поля всех идей в файле сверены с копией базы SQLite: совпали. Приложение удалено только на `emulator-5580`; отсутствие пакета подтверждено, затем выполнена новая установка. После первого запуска повторно создались 6 новых демонстрационных идей.

Файл импортирован через системный выбор документа. В базе стало 13 идей: 6 новых примеров + все 7 записей из резервной копии. Для каждой импортированной идеи подтверждены все поля, кроме нового локального идентификатора, и соответствующая категория по имени; даты, текст, статус, важность и голосовой признак совпали с копией. Пользовательская тестовая идея восстановилась ровно один раз, внешние ключи корректны, после холодного запуска осталось 13 записей.

Это **добавляющий импорт**, а не замена базы снимком. Старые демонстрационные идеи из копии отличаются датами от заново созданных примеров, поэтому обе версии остаются. Категории при совпадении имён объединяются с существующими, их локальные свойства не перезаписываются. Для сценария «после переустановки получить в точности прежний список» это ограничение следует учитывать; данные идей не потеряны.
